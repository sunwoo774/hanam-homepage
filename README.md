# 하남 한일윌로모터펌프 - 파워펌프 서비스센터

하남시 지역 지하수 모터펌프, 배수펌프, 심정펌프, 압력탱크, 동파, 인버터 낙뢰 피해 출장수리 전문 웹사이트입니다.
기존 8개 지역 사이트와 색상·레이아웃·서비스 표현 방식을 전부 다르게 제작했습니다.

## 이 사이트만의 차별점

- **톤**: 딥 플럼(자주보라) + 라임 그린 + 라일락 배경. "미사강변 신도시 모던" 톤.
  (가평=네이비/골드, 홍천=딥그린/코랄, 남양주=차콜/오렌지, 광주=코발트/테라코타, 여주=버건디/골드, 이천=모노크롬/레드, 춘천=틸/피치, 포천=올리브/앰버)
- **헤더**: 반투명 블러 화이트 고정 바.
- **히어로**: 플럼 그라디언트 배경 + 하단에 흰색 정보 카드가 겹쳐 올라오는 오버랩 구조(스탯 + 심도 배지).
- **증상 안내**: 좌측 라임 액센트 바가 있는 셀프체크 아코디언(details) 2열 그리드.
- **서비스 표현**: 큰 번호(01~04)가 배경에 깔린 스텝 카드.
- **출장권역**: 핀 번호(1~4) 리스트로 하남 자체 권역 우선 안내.
- **작업사례**: 3건(수중모터 인양 / 배수펌프 교체 / 인버터 제어반 점검), 실사진 반영.
- **배수펌프 사진**: 세로 대형 배치 + 클릭 시 라이트박스 확대.
